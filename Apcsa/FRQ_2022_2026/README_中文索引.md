## 二轮复习建议

按你目前课件的专题安排，可以这样取题：

| 专题 | 可选真题 |
| --- | --- |
| 方法、条件与循环 | 2022 Q1、2023 Q1、2024 Q1、2025 Q1、2026 Q1 |
| 类与对象状态 | 2023 Q2、2024 Q2、2025 Q2、2026 Q2 |
| String + 对象数组/ArrayList | 2022 Q3、2023 Q3、2024 Q3、2025 Q3、2026 Q3 |
| 二维数组与对象网格 | 五年的 Q4 |
| 继承拓展 | 2022 Q2；不当作当前继承编程必考题 |

先做专题训练，再用 2026 全套检查对新形式的适应。旧题适合知识点复习，但不能把所有历史题型要求原样当作当前模拟卷标准。

每题订正四步：

1. 用自己的话写前置条件、返回值、是否允许修改输入。
2. 独立写代码并手推一个边界，不先看答案。
3. 打开同年份评分文件，逐条标出已拿到和未拿到的评分点。
4. 记录“错误假设 → 最小反例 → 修正规则”，隔几天脱离答案重写。
