## 学习顺序

| 学习阶段              | 学什么                               | 进入下一阶段的标准                   |
| --------------------- | ------------------------------------ | ------------------------------------ |
| 1. Python 基础        | 变量、条件、循环、列表、字典、函数   | 能独立写函数，遍历一组样本           |
| 2. 数据与分类入门     | 特征、标签、预测、准确率；NumPy 基础 | 能解释程序的输入、输出和错误预测     |
| 3. 逻辑与知识表示     | 真值表、蕴含、谓词、量词、规则推理   | 能把文字规则写成逻辑表达式并解释结论 |
| 4. 决策树与随机森林   | 数据划分、信息增益、过拟合、集成     | 理解模型如何从数据选择规则           |
| 5. 线性模型与神经网络 | 点积、损失、梯度下降、前向与反向传播 | 能解释训练如何改变参数               |
| 6. 综合项目           | 模型比较、结果分析、偏见与伦理       | 能独立完成实验并说明局限             |
