## 📚 AI 入门

## 1. AI 导论：教材第 1、2 章的核心概念

### 1.1 什么是人工智能？——第 1 章

人工智能研究如何构建能够感知、推理、学习并采取行动的系统。不同任务需要不同能力，例如识别图片、规划路线、从事实推出结论或根据数据预测类别。

研究 AI 的四种视角：

| 视角 | 关注的问题 | 课堂理解 |
|---|---|---|
| 像人一样思考 | 系统是否模拟人的思维过程？ | 研究人如何解决问题 |
| 像人一样行动 | 系统行为是否表现得像人？ | 例如语言交流 |
| 合理地思考 | 推理是否符合逻辑？ | 从已知事实推出结论 |
| 合理地行动 | 行动是否有助于实现目标？ | 根据可获得的信息选择行动 |

本课重点使用最后一种视角。**AI 不一定要模仿人，也不一定都使用机器学习。**机器学习是 AI 的一个重要方向，关注如何从数据或经验中改进表现。

提问：“一个会下棋的程序必须像人一样思考，才能下好棋吗？”

### 1.2 两种入门方式：规则与学习

| 方式 | 人提供什么？ | 程序做什么？ | 本课例子 |
|---|---|---|---|
| 人工规则 | 明确条件与行动 | 按规则作出判断 | 距离小于 20 厘米就停止 |
| 从数据学习 | 数据、学习目标及方法等 | 根据数据选择或调整模型 | 比较候选水果分类阈值 |

### 1.3 什么是智能体 Agent？——第 2 章

**智能体是能够感知环境，并通过行动影响环境的系统。**机器人可以使用传感器与电机；软件智能体也可以读取消息、文件等信息，并通过软件操作采取行动。

以避障机器人为例：

| 部分 | 机器人例子 | 教师可以问 |
|---|---|---|
| 环境 environment | 机器人所在的房间及障碍物 | 它在哪里活动？ |
| 感知 perception | 读取前方距离 | 它能获得什么信息？ |
| 决策 | 根据距离选择下一步 | 它如何作出判断？ |
| 行动 action | 停止或前进 | 它能做什么？ |

课堂口述：机器人读取距离，选择行动；行动之后环境可能改变，因此下一次需要再次读取距离。后面的代码仅演示这个过程中的一次判断。

### 1.4 什么是“合理的行动”？

行动是否合理，要结合目标、可获得的信息和可采取的行动判断。

例如机器人的目标同时包括：**避免碰撞、到达终点、合理使用电量**。一直停止可能避免部分碰撞，却无法完成到达终点的任务。

| 情况 | 候选行动 | 学生解释 |
|---|---|---|
| 前方很近处有障碍物 | 停止或改变方向 | 为什么？ |
| 前方没有障碍物 | 向目标前进 | 为什么？ |
| 电量不足 | 根据任务考虑充电等行动 | 还需要知道什么？ |

本课的简化程序只有“停止、前进”两个选项；充电、转向等留作讨论，不要求立即编程。

**合理不等于永远成功，也不等于知道未来。**传感器有误差或信息不完整时，即使根据当前信息作出合理选择，结果仍可能不理想。

### 1.5 智能体也可以从简单规则开始

教材第 2 章介绍不同智能体结构。今天只体验“根据当前观察，匹配条件并采取行动”的简单反射思路：

> 如果前方距离小于 20 厘米，就停止；否则前进。

它不记录过去，也不从经验自动调整阈值。后续可以逐步加入记忆、目标、行动规划和学习。

### 1.6 今天我们要让程序做什么？

下面这些系统都需要根据输入作出判断：

| 场景 | 输入 | 输出 |
|---|---|---|
| 机器人避障 | 前方障碍物的距离 | 停止或前进 |
| 邮件分类 | 邮件的文字及其他信息 | 正常邮件或垃圾邮件 |
| 水果分类 | 重量、颜色等特征 | 一个预测类别 |

今天先用简单程序体验“判断”。真实 AI 系统可能涉及更多输入、更复杂的规则和训练过程。

## 3. AI 小例子一：避障小机器人

### 3.1 先用文字设计规则

假设机器人只考虑前方距离，单位是厘米：

> 距离小于 20 厘米时停止；否则前进。

| 距离 | 应采取的行动 |
|---:|---|
| 10 | __________ |
| 19 | __________ |
| 20 | __________ |
| 30 | __________ |

### 3.2 用 Python 表达规则

```python
distance = 15

if distance < 20:
    print("停止")
else:
    print("前进")
```

| 写法 | 含义 |
|---|---|
| `if` | 如果条件成立 |
| `distance < 20` | 判断距离是否小于 20 |
| `:` | 后面开始一个代码块 |
| 缩进的语句 | 属于上面的代码块 |
| `else` | 条件不成立时 |

使用英文标点，代码块统一缩进 4 个空格。

### 3.3 动手：只改一个地方

将 `distance` 分别改为 10、19、20、30。每次先预测，再运行。

**边界讨论：** 距离恰好是 20 时为什么前进？如果希望 20 也停止，应修改哪个符号？

### 3.4 第二个输入：电量（有基础者选讲）

现在加入规则：距离太近，**或者**电量低于 10%，机器人停止。

```python
distance = 30
battery = 5

if distance < 20 or battery < 10:
    print("停止")
else:
    print("前进")
```

`or` 表示“至少一个条件成立”。把它改成 `and` 后，需要两个条件同时成立。

| distance | battery | 使用 or 的行动 | 使用 and 的行动 |
|---:|---:|---|---|
| 15 | 5 | __________ | __________ |
| 15 | 80 | __________ | __________ |
| 30 | 5 | __________ | __________ |
| 30 | 80 | __________ | __________ |

### 3.5 这个程序会学习吗？

这是一个**人工规则控制器**，可以用来理解简单智能体的“观察—行动”过程。我们规定了 20 和 10 这两个数，程序没有从数据中学习它们。

真实机器人还需处理传感器误差、运动速度等因素；本例仅用于理解程序判断。

## 4. AI 小例子二：水果分类器

### 4.1 什么是分类？

分类：根据输入信息，为一个样本预测类别。

| 词语 | 本例含义 |
|---|---|
| 样本 sample | 一个水果 |
| 特征 feature | 水果重量，单位为克 |
| 标签 label | 已知的真实类别：apple 或 orange |
| 预测 prediction | 程序给出的类别 |
| 阈值 threshold | 用来划分重量的临界值 |

**注意：** 以下水果数据是为了演示编程而设计的。现实中苹果和橙子的重量可能重叠，不能仅凭重量可靠识别。

### 4.2 观察用于选择规则的数据

| 样本 | 重量 | 真实类别 |
|---|---:|---|
| A | 110 | orange |
| B | 130 | orange |
| C | 170 | apple |
| D | 190 | apple |

学生任务：选一个阈值，将轻的预测为 orange，重的预测为 apple。

一个候选规则是：

> 重量大于或等于 150 克，预测为 apple；否则预测为 orange。

### 4.3 一个样本的预测

```python
weight = 170
threshold = 150

if weight >= threshold:
    prediction = "apple"
else:
    prediction = "orange"

print(prediction)
```

**学生动手：** 分别测试 130、149、150、170。

### 4.4 增加一个反例

现在看到一个新水果：重量 160 克，真实类别是 orange。

| 重量 | 真实类别 | 按 150 克规则预测 | 是否正确 |
|---:|---|---|---|
| 160 | orange | __________ | __________ |

讨论：

1. 程序是否执行错了？
2. 还是规则没有描述所有情况？
3. 将阈值改为 165 会怎样？
4. 换一组数据，这个修改还会有效吗？

程序可以正确执行一个不够准确的规则。要区分**代码错误**与**规则或模型的预测错误**。

## 5. 选讲：把判断写成函数

> 零基础学生可以先跳到第 6.1 节，用表格完成评估。函数代码由老师演示，不要求当场独立默写。

### 5.1 为什么需要函数？

每预测一个水果，都复制整段判断代码会难以维护。函数可以复用同一个步骤。

```python
def predict(weight, threshold=150):
    if weight >= threshold:
        return "apple"
    return "orange"


print(predict(170))
print(predict(130))
print(predict(160, threshold=165))
```

| 写法 | 含义 |
|---|---|
| `def` | 定义函数 |
| `weight` | 输入参数 |
| `threshold=150` | 不指定阈值时使用 150 |
| `return` | 将结果交给调用者，并结束函数 |
| `predict(170)` | 调用函数，传入 170 |

`return` 不会自动显示内容，所以这里用 `print(...)` 显示返回值。

## 6. 怎样检查预测效果？

### 6.1 先手工评估

固定阈值为 150。下面这组新数据此前没有参与选择阈值：

| 样本 | 重量 | 真实类别 | 预测类别 | 是否正确 |
|---|---:|---|---|---|
| E | 120 | orange | __________ | __________ |
| F | 145 | orange | __________ | __________ |
| G | 160 | orange | __________ | __________ |
| H | 180 | apple | __________ | __________ |

\[
\text{准确率} = \frac{\text{预测正确的样本数量}}{\text{总样本数量}}
\]

这组数据中正确数量是 ______，总数是 ______，准确率是 ______。

**准确率回答的是“在这组数据上有多少预测正确”，不是保证未来一定有相同表现。**

### 6.2 用列表保存多个样本（选讲）

```python
weights = [120, 145, 160, 180]
labels = ["orange", "orange", "orange", "apple"]

print(weights[0])  # 120
print(labels[0])   # orange
```

两个列表相同下标的位置对应同一个样本。Python 下标从 0 开始。

### 6.3 完整评估程序（已有循环基础者）

```python
def predict(weight, threshold=150):
    if weight >= threshold:
        return "apple"
    return "orange"


weights = [120, 145, 160, 180]
labels = ["orange", "orange", "orange", "apple"]
correct = 0

for i in range(len(weights)):
    prediction = predict(weights[i])
    actual = labels[i]
    print(weights[i], actual, prediction)
    if prediction == actual:
        correct += 1

accuracy = correct / len(weights)
print(f"准确率：{accuracy:.0%}")
```

预期输出：

```text
120 orange orange
145 orange orange
160 orange apple
180 apple apple
准确率：75%
```

这里假设两个列表等长且非空。正式写成通用评估函数时，应检查长度与空数据。

### 📌 讨论

如果一组数据里有 99 个 orange 和 1 个 apple，一个总猜 orange 的程序能得到 99% 准确率。它真的学会区分两类水果了吗？

先理解这个问题，不必在第一次课深入所有评估指标。

## 7. 进阶体验：让程序从数据选择规则

> 时间不足时可留到下一课。零基础学生只比较下面的表格；已有基础者再读循环代码。

### 7.1 人工指定规则与数据选择规则

| 方式 | 阈值从哪里来？ |
|---|---|
| 人工规则 | 人直接指定，如 150 |
| 简化学习过程 | 给定带标签数据，程序比较候选阈值，选出得分较高的规则 |

我们仍然规定了规则形式：“大于等于阈值预测 apple”。程序只在这个范围内选择阈值，不能因此解决任意问题。

### 7.2 回到训练数据

使用第 4.2 节的 A–D：110、130 为 orange，170、190 为 apple。

| 候选阈值 | 正确数 / 总数 | 训练准确率 |
|---:|---|---|
| 120 | 3 / 4 | 75% |
| 150 | 4 / 4 | 100% |
| 180 | 3 / 4 | 75% |

在这三个候选值中，程序应选哪一个？

### 7.3 完整代码：搜索候选阈值（选讲）

```python
def predict(weight, threshold):
    if weight >= threshold:
        return "apple"
    return "orange"


train_weights = [110, 130, 170, 190]
train_labels = ["orange", "orange", "apple", "apple"]
candidates = [120, 150, 180]
best_threshold = None
best_correct = -1

for threshold in candidates:
    correct = 0
    for i in range(len(train_weights)):
        prediction = predict(train_weights[i], threshold)
        if prediction == train_labels[i]:
            correct += 1
    print("候选阈值：", threshold, "正确数量：", correct)
    if correct > best_correct:
        best_correct = correct
        best_threshold = threshold

print("选定阈值：", best_threshold)

# 选好规则后，再在未参与选择的样本上评估
test_weights = [120, 145, 160, 180]
test_labels = ["orange", "orange", "orange", "apple"]
test_correct = 0
for i in range(len(test_weights)):
    if predict(test_weights[i], best_threshold) == test_labels[i]:
        test_correct += 1
print(f"测试准确率：{test_correct / len(test_weights):.0%}")
```

运行结果：三个候选值分别正确 3、4、3 次；选定阈值 150；测试准确率 75%。若候选阈值并列，该代码保留先遇到的阈值。

### 7.4 为什么训练 100%，测试却是 75%？

因为未见过的数据不一定符合训练数据中的简单规律。这说明需要检查模型在新数据上的表现，而不只看训练得分。

这个小例子还不能证明是哪一种原因导致误差；可能涉及数据量少、特征不足、规则形式受限等。

**重要约定：** 测试集用于最终检查。看到测试结果后反复调阈值，会使它参与规则选择；此后应把它视为开发或验证数据，并另留新的测试数据。

### 10.5 作业 C 参考代码

```python
def predict(weight, threshold):
    return "apple" if weight >= threshold else "orange"


def evaluate(weights, labels, threshold):
    if len(weights) != len(labels):
        raise ValueError("特征与标签数量不同")
    if len(weights) == 0:
        raise ValueError("样本不能为空")
    correct = 0
    for weight, actual in zip(weights, labels):
        if predict(weight, threshold) == actual:
            correct += 1
    return correct / len(weights)


print(evaluate([120, 145, 160, 180],
               ["orange", "orange", "orange", "apple"], 150))  # 0.75
```

此实现用于约定输入为有效数值、标签为 apple / orange 的课堂数据。需要处理真实外部数据时，还应增加类型和标签范围校验。
