# 沿用学校框架：空间囚徒困境与遗传算法

这是学校 CellMap / CAWrapper / GA / Chromosome 代码的整合改造版，不是前一个独立窗口版本。

## 运行

解压，保持所有 `.py` 文件在同一个文件夹中。在这个文件夹打开终端：

```bash
python3 CAWrapper.py
```

也可以运行 `GAWrapper.py`，它现在启动同一个项目。运行 `CellMap.py` 也可以启动窗口。

需要支持 Tkinter 的桌面 Python 环境。正常运行不需要 NumPy、Pandas 或其他第三方库。

仅“Save Picture”导出 PNG 功能需要 Pillow，可选安装：

```bash
python3 -m pip install pillow
```

图片保存到终端当前工作目录。若环境报缺少 tkinter，需为当前 Python 安装对应的 Tk 支持；Pillow 不能代替 Tkinter。无桌面的远程环境可运行下方测试，但不能直接显示窗口。

| 文件 | 沿用与修改 |

| GA.py | 保留种群初始化、父母选择、交叉、变异、下一代和最好/最差等组织方式；全局锦标赛选择改成当前细胞与更优秀邻居的局部选择 |

## 界面使用

- Start / Stop：开始、暂停。
- Reset：重新随机生成策略，代数归零。没有死亡细胞，原 Clear 不再清空网格。
- Speed：沿用四档速度。
- Skip Generations：每次刷新前推进几代，正整数。过大时界面响应会变慢。
- Strategy Length：20 或 50。修改后按 Enter，会重新生成整个网格。
- Mutation：0–1，每个新策略发生一次单点变异的概率，默认 0.03。
- 修改输入框后按 Enter 或点击 Start 应用。
- 点击：非全合作策略设为全 C，全合作策略设为全 D；拖动使用本次点击的同一选择。
- 红色：全 D；绿色：全 C；中间颜色：按字符串中的 C 比例插值。
- 顶部 C：当前全部策略字符中 C 的比例，不是“至少含一个 C 的细胞比例”。
- 鼠标信息：显示当前位置、合作比例和当前一代的对局总分。

## 每一代的过程

1. 400 个细胞始终存在，每格保存 20 或 50 位固定 C/D 字符串。
2. 每个细胞与八个邻居分别完成整段字符串的迭代对局。
3. 每一对邻居只计算一次，同时累加双方得分。
4. 比较当前细胞与邻居的总分。只有存在严格更高分邻居时才交叉。
5. 所有新策略生成完后统一替换旧网格，不能边计算边覆盖。
6. 为显示的新一代更新分数，并刷新合作颜色。

收益：CC → (2,2)，CD → (0,3)，DC → (3,0)，DD → (1,1)。例如全 C 网格、20 回合时，每格得分为 8×20×2=320；全 D 时为 160。

## 图片没有明确的细节，本版采用的约定

- 边界：沿用学校取模环绕，每格恰好八个不同邻居；网格至少 3×3。
- 配偶：选择最高分邻居，并列时随机选择一个。
- 交叉：存在更优秀邻居就交叉，随机单点交叉产生两个孩子，随机保留一个作为该格下一代。父母本身不被修改。
- 变异：沿用学校 GA 的“每个孩子以 mutProb 概率发生一次单点变异”，翻转 C/D。没有更优秀邻居时，也允许变异。
- 默认变异率 0.03：并不是每个字符有 3% 的变异概率。与前一个独立版本的逐位变异不同。
- 学校原 GA 的 crossProb=0.8 不再额外使用，因为图片说有更优秀邻居就进行交叉。
- 学校原目标文本适应度越低越好；本题总分越高越好。compareFitness 保留负数表示自身更好的约定，但内部比较方向已经调整。
- 每回合行为由字符串对应位置决定，没有额外引入 tit-for-tat 等根据历史响应的策略。
