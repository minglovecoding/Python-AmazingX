## ACSL课程规划

| 课次 | 主题                 | 课堂重点                                        | 配套练习                 |
| ---- | -------------------- | ----------------------------------------------- | ------------------------ |
| 1    | 数制基础             | 位权；二、八、十、十六进制转换；二进制分组转换  | 编程实现进制转换         |
| 2    | 数制进阶             | 不同进制的加减乘；小数转换；混合进制计算        | 数字拆分与进位模拟       |
| 3    | 递归函数基础         | 终止条件；分段函数；递归展开与返回              | 单变量递归求值           |
| 4    | 递归函数进阶         | 双变量、多分支、嵌套递归；用表格整理计算        | 递归实现与结果核对       |
| 5    | 程序阅读             | ACSL 伪代码；运算规则；分支、循环、数组跟踪     | 手算与运行结果对照       |
| 6    | 第一轮模拟与讲评     | 计时短答题；错误分类；薄弱专题复习              | 一道完整编程题           |
| 7    | 表达式基础           | 前缀、中缀、后缀的结构与相互转换                | 表达式转换练习           |
| 8    | 表达式求值           | 用栈求值；非交换运算的操作数顺序                | 实现后缀表达式求值       |
| 9    | 位串操作             | 按位运算；逻辑移位；循环移位；固定长度          | 实现位串操作             |
| 10   | LISP 基础            | 原子、列表、引用、赋值；`CAR`、`CDR`            | 嵌套列表手算             |
| 11   | LISP 进阶            | `CONS`、`REVERSE`、`EVAL`；组合函数与复杂表达式 | LISP 与位串综合训练      |
| 12   | 第二轮模拟与讲评     | 三个专题计时训练；步骤规范                      | 一道完整编程题           |
| 13   | 布尔代数基础         | 逻辑运算；真值表；表达式求值                    | 枚举全部输入组合         |
| 14   | 布尔代数进阶         | 德摩根定律；表达式化简；满足条件的组合计数      | 化简与枚举交叉验证       |
| 15   | 栈与队列             | LIFO、FIFO；操作序列；多个结构之间的数据流动    | 操作指令模拟             |
| 16   | 二叉搜索树与堆       | 建树、遍历、查找与删除；堆和优先队列操作        | 手算结构变化             |
| 17   | 自动机与正则表达式   | 状态转移；接受字符串；连接、选择、重复          | 编程模拟自动机           |
| 18   | 第三轮模拟与讲评     | 布尔代数、数据结构、自动机综合训练              | 一道完整编程题           |
| 19   | 图论基础             | 有向图、无向图；度、路径、环、连通性；树与森林  | 邻接矩阵与邻接表         |
| 20   | 图论问题训练         | 路径与环的辨别、枚举；图与树的性质              | 小规模路径搜索           |
| 21   | 数字电路             | 逻辑门识别；逐层计算；电路转布尔表达式          | 输出条件与输入组合计数   |
| 22   | ACSL 汇编基础        | ACC、内存、标签；加载、存储、算术运算           | 指令执行跟踪表           |
| 23   | ACSL 汇编进阶        | 条件跳转、循环、输入输出；反推程序功能          | 汇编程序综合分析         |
| 24   | 第四轮模拟与课程总结 | 第四轮计时训练；全年知识查漏补缺                | 综合编程题与个人复习清单 |

***

**第一轮：数制、递归、程序阅读**

| 专题       | 英文名称                   | 需要掌握的内容                                               |
| ---------- | -------------------------- | ------------------------------------------------------------ |
| 计算机数制 | Computer Number Systems    | 二、八、十、十六进制的表示与转换；不同进制的加减乘运算；含小数部分的进制转换与运算 |
| 递归函数   | Recursive Functions        | 递归定义与终止条件；分段递归函数；单变量、双变量递归求值；逐层展开与返回 |
| 程序阅读   | What Does This Program Do? | 阅读 ACSL 伪代码；跟踪变量、条件分支、循环、数组等操作；计算最终变量值或输出 |

**第二轮：表达式、位串、LISP**

| 专题                   | 英文名称                      | 需要掌握的内容                                               |
| ---------------------- | ----------------------------- | ------------------------------------------------------------ |
| 前缀／中缀／后缀表达式 | Prefix/Infix/Postfix Notation | 三种表达式的识别、相互转换和求值；运算顺序、括号及表达式结构 |
| 位串操作               | Bit-String Flicking           | 按位 NOT、AND、OR、XOR；逻辑左移、右移；循环左移、右移；复合表达式求值与未知位推断 |
| LISP                   | LISP                          | 原子与列表；嵌套列表；引用符号 `'`；`SET`、`SETQ`、`EVAL`、`ATOM`；`CAR`、`CDR`、`CONS`、`REVERSE` 及组合操作 |

**第三轮：布尔代数、数据结构、自动机**

| 专题                       | 英文名称                     | 需要掌握的内容                                               |
| -------------------------- | ---------------------------- | ------------------------------------------------------------ |
| 布尔代数                   | Boolean Algebra              | AND、OR、NOT 等逻辑运算；真值表；布尔代数定律与德摩根定律；表达式化简；统计使表达式为真或假的输入组合 |
| 数据结构                   | Data Structures              | 栈、队列、二叉搜索树、优先队列／堆；操作过程模拟；树的构建、遍历及相关操作 |
| 有限状态自动机与正则表达式 | FSAs and Regular Expressions | 状态、转移、初始状态与接受状态；判断字符串是否被接受；正则表达式的连接、选择、重复及其描述的字符串集合 |

**第四轮：图论、数字电路、汇编**

| 专题     | 英文名称            | 需要掌握的内容                                               |
| -------- | ------------------- | ------------------------------------------------------------ |
| 图论     | Graph Theory        | 顶点与边；有向图、无向图；路径、简单路径、环；连通性与连通分量；完全图；树与森林 |
| 数字电路 | Digital Electronics | BUFFER、NOT、AND、OR、NAND、NOR、XOR、XNOR 门；电路输出计算；电路与布尔表达式的对应；满足输出条件的输入组合 |
| 汇编语言 | Assembly Language   | ACSL 自定义汇编；累加器 ACC；内存与标签；数据加载、存储、算术运算、跳转、输入输出；跟踪程序执行 |
