## 📚IGCSE-计算机课程计划

| ------------------------------------- | ------------------------------------------------------------ | -------- |
| 1. Data Representation                | 进制、Binary/Hex、文本、声音、图片、压缩                     | 4–5 节   |

| 3. Hardware                           | CPU、输入输出、存储、网络硬件                                | 4 节     |
| 4. Software                           | System/Application Software、Interrupt、Language、Translator、IDE | 2–3 节   |
| 5. Internet and Its Uses              | Internet、WWW、Digital Currency、Cybersecurity               | 2–3 节   |
| 6. Automated & Emerging Technologies  | Automated Systems、Robotics、AI                              | 2–3 节   |
| 7. Algorithm Design & Problem Solving | Development Cycle、Decomposition、Validation、Testing、Trace Table、Algorithms | 3–4 节   |
| 8. Programming                        | Programming Concepts、Arrays、File Handling                  | 4–5 节   |
| 9. Databases                          | Database、SQL 等                                             | 1–2 节   |
| 10. Boolean Logic                     | Logic Gates、Truth Tables、Logic Expressions                 | 2 节     |
